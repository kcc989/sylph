# Sylph marketing and documentation site

A TanStack Start app that explains Sylph and documents it. It is deployed as its
own Cloudflare Worker from `alchemy.run.ts` (the `Documentation` website).

## Run it

```sh
bun --cwd apps/docs dev        # http://localhost:3001
bun --cwd apps/docs build
bun --cwd apps/docs test
```

## Layout

```text
content/docs/          MDX pages, and the meta.json files that order them
source.config.ts       Fumadocs collection definition
src/lib/source.ts      The Fumadocs loader, server side only
src/lib/docs-content.tsx  The client loader that renders a compiled MDX page
src/routes/index.tsx   The marketing home page
src/routes/docs.tsx    The documentation shell, with the page tree
src/styles/globals.css The shared design system plus the Fumadocs preset
```

## Add a page

1. Create an `.mdx` file under `content/docs`, with `title` and `description`
   frontmatter.
2. Add its name to the `pages` array of the `meta.json` beside it.
3. Run `bun --cwd apps/docs test`. The content tests check frontmatter, the
   `meta.json` entries, and every internal documentation link.

`.source` is generated by Fumadocs from `content/docs` and is not committed. The
Vite plugin regenerates it during `dev` and `build`; `bun --cwd apps/docs
typecheck` regenerates it first as well.

## Styling

The site imports `@workspace/ui/globals.css` for the Sylph design tokens, then
maps the Fumadocs `--color-fd-*` variables onto those tokens through
`fumadocs-ui/css/shadcn.css`. Both light and dark themes follow the shared
palette, so the site does not carry a second visual system.
