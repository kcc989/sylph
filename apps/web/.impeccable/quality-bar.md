# Quality bar: Conductor-adjacent workbench

Reference: `.impeccable/references/conductor-grouping.png`

The bar is Conductor's calm density and legible Repository → Workspace nesting, not its exact chrome. Sylph must reach that level of information compression, keyboard-scale controls, consistent separators, and clear active-work hierarchy. It must exceed the reference in browser continuity: the running product, browser-control state, changes, and checks remain part of the same readable workspace.

The build keeps the left hierarchy, durable agent transcript, and review topology familiar while establishing Sylph through warm near-black surfaces, coral selection, aqua live state, its faceted vector mark, and an explicit browser/device-control seam. Mobile adapts the simultaneous desktop layout into Agent, Preview, and Review modes without hiding repository access.
