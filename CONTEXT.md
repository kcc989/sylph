# Sylph

Sylph gives a user durable coding workspaces backed by repositories inside an organization.

## Language

**Organization**:
A membership boundary that owns repositories.

**Repository**:
The canonical source history a user creates inside an organization.
_Avoid_: Project

**Workspace**:
The durable place where a user works on a repository with an agent. An initial Workspace is created automatically after its Repository.
_Avoid_: Environment, task
