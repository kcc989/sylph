# Security policy

Do not report vulnerabilities in public issues.

Email the repository owner through the private contact method on their GitHub profile with the affected revision, impact, reproduction steps, and any suggested mitigation. Please allow time for acknowledgement and coordinated remediation before public disclosure.

Sylph handles provider credentials and runs agent-authored changes. Operators are responsible for protecting deployment secrets, restricting Cloudflare account access, applying releases, and reviewing changes before production deployment.
