# Cloudflare agent lifecycle integration

This change combines the six E2E gap assignments into one Sylph branch. It adds the supported starter contract, D1 recovery, production observations and repair Workspaces, broader resource management, browser journey acceptance, and combined lifecycle/preservation tooling.

Implementation and live proof are separate. The release remains blocked until the compatible external starter is published and pinned. The combined lifecycle must then be exercised on a disposable Installation at the exact integrated commit.
