# Project templates are forked Template Repositories

A Project template is a git repository at a pinned ref, not a Sylph-owned format. Sylph imports it once per Installation into an Artifacts Template Repository and forks that repository for every new Project, so creation is instant, history is preserved, and the Project records the template key, repository, and commit as its origin without keeping a live link. The template declares everything Sylph needs through the existing Check contract package scripts and its own `AGENTS.md`, and Sylph passes the Project slug to deploy stages as `SYLPH_PROJECT` so a template can derive unique Cloudflare resource names. Built-in templates are constants pinned to a ref; "Start fresh" forks the default template, a GitHub import can stay connected as an Upstream Repository or be a one-off copy, and an empty repository remains available only as an advanced option because it cannot pass a Check.
